Support

Questions, bugs or a request: open an issue and we'll reply there.

Contact

Open a support issue on GitHub. Issues are public, so please don't include passwords, API tokens, or details about your buildings that you wouldn't publish.

Helpful to include:

  • your Atlassian site's address (your-site.atlassian.net)
  • what you did, what you expected, and what happened
  • the work order key (for example FAC-12) if the problem is on a work order

Common questions

A work order wasn't flagged

Walkdown matches whole equipment tags in the work order's summary and description, and only checks work orders in the Jira space linked to the site. Check that the tag is written exactly as it appears on the model (RTU-1, not RTU1) and that the decision is still standing.

A work order is blocked and I need to start it

Open the Walkdown panel on the work order and choose Reaffirm, Supersede or Withdraw. Reaffirming needs edit permission on the work order; superseding needs a site approver to accept the new decision.

Finding blocked work orders

Search Jira with walkdownStatus = conflict.

Removing Walkdown

A Jira admin can uninstall it from Apps → Manage apps. See the privacy policy for what happens to its data.
